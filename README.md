# guacamole

A recipe for my favorite guacamole. It's vegan: it uses vegetable bouillon, not chicken bouillon.

## Ingredients

The full list is in [`ingredients.txt`](ingredients.txt):

- avocado
- lime juice
- salt
- tomato
- jalapeño
- onion
- garlic
- cilantro
- vegetable bouillon

Quantities and preparation steps aren't written down yet.
